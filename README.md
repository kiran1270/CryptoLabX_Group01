# CryptoLabX - Group 01

## Cryptography Laboratory (22CPP307)

CryptoLabX is a modular command-line toolkit developed for
Cryptography Laboratory assignments. The project is designed to
provide a common structure for implementing cryptography and
cryptanalysis techniques in future assignments.

## Group
Group 01

## Project Structure

- classical/  : Classical cryptography algorithms
- attacks/    : Cryptanalysis and attack techniques
- math/       : Mathematical functions
- modern/     : Modern cryptography algorithms
- analysis/   : Data and text analysis
- datasets/  : Text datasets
- outputs/    : Generated outputs
- docs/       : Documentation
- tests/      : Testing files
- utils/      : Utility functions
- main.py     : Main command-line interface
- README.md   : Project documentation
- requirements.txt : Required packages

## Assignment 1

Assignment 1 establishes the basic toolkit structure.
It includes a menu-driven CLI, text-file analysis, dataset
handling and execution logging.

## Menu

1. Encrypt
2. Decrypt
3. Attack
4. Analyze
5. Exit

Encryption, decryption and attack modules are reserved for
future assignments.

## Future Scope

The toolkit will be extended with classical ciphers,
cryptanalysis techniques, mathematical operations and
modern cryptographic algorithms.
